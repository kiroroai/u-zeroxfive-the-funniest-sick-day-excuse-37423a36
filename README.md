# The Funniest Sick-Day Excuse

A [make.fun](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36) bounty entry: a program that writes the funniest one-line sick-day excuse to `/output/entry.txt`.

`main.py` writes a single line, under 200 characters, that someone could send to call in sick — half believable, fresh, with the twist landing on the last word:

> Sorry, can't come in today — I tried to fix a leaking tap, flooded the bathroom, and my goldfish has started charging me rent.

## Run

```sh
python3 main.py  # writes $MAKEFUN_OUTPUT_DIR/entry.txt (default /output)
```

Deterministic: two runs produce byte-identical output (sha256 `746398c4267e7319dc8e3e8af54522d78208a94e607caffe401ddd7f64f54f2b`).
